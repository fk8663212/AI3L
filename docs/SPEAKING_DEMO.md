# Macro／Micro 英語口說 Demo：僅範例展示，尚未整合正式流程

本分支為 `feature/macro-micro-speaking`。目前交付的是給老師確認形式的固定資料展示，**Macro／Micro 雙層圖尚未實作到正式學生學習與研究流程中**。

## 目前可以展示的內容

同一份大稻埕範例資料支援以下操作：

- 切換原本的單層概念圖與 Macro／Micro 雙層圖。
- Macro 按「入口 → 攤位 → 特色美食 → 總結」安排講述順序。
- 選取段落時，同步切換 Micro 子圖、英文關鍵詞與句首。
- 「特色美食」顯示「糕餅店 → 販售 → 鳳梨酥」、`pineapple cake` 與 `One popular snack here is …`。
- 使用上一段／下一段、鍵盤方向鍵與重設展示。

這些資料與提示都是預先寫好的範例，不是依學生上傳內容或 AI 即時生成。

## 如何開啟

直接用瀏覽器開啟 [`../public/demo/index.html`](../public/demo/index.html)。此 HTML 已包含展示所需的程式、樣式與資料，可單獨複製並離線使用，不需要登入、資料庫或 API Key。

在 GitHub 檔案頁需先下載 HTML，再用本機瀏覽器開啟。若已啟動完整 Next.js 平台，可開啟 <http://localhost:3000/demo/index.html>；此頁仍是固定範例展示。

展示頁頂端會持續顯示「固定範例展示｜尚未整合正式學生學習流程」。
